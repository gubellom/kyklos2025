This folder contains data about geographic distance. The "distance.do" file keeps information to compute the distance from the capital. The dataset is named "geo_cepii.dta"

You can download the dataset at: https://www.cepii.fr/cepii/en/bdd_modele/bdd_modele_item.asp?id=6

Reference dataset: Mayer, T., and S. Zignago. 2011. “ Notes on CEPII's Distances Measures: The GeoDist Database.” CEPII Working Papers 2011-25. http://www.cepii.fr/CEPII/en/publications/wp/abstract.asp?NoDoc=3877.
