V-Dem-CY-FullOthers_STATA_v13
This folder contains the V-Dem dataset. The "aggregatevar.do" file generates the dataset poliV.dta, which keeps the variables of interest. 

The raw data is: V-Dem-CY-Full+Others-v13.dta

Citation: Coppedge, M., J. Gerring, C. H. Knutsen, et al. 2023. “ V-Dem Dataset v13.” Varieties of Democracy (V-Dem) Project. https://doi.org/10.23696/vdemds23. 

You can find the raw data (V-Dem Dataset v13) at: https://v-dem.net/data/dataset-archive/
