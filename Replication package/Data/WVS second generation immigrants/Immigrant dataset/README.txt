The folder contains the IVS dataset (The Integrated Values Surveys (IVS) dataset 1981-2022). The IVS is constructed from the EVS and WVS trend files.

The IVS dataset can be downloaded and constructed at: https://www.worldvaluessurvey.org/WVSEVStrend.jsp

Versions used: 

C. Haerpfer, R. Inglehart, A. Moreno, et al. (Eds.) 2022. World Values Survey Trend File (1981-2022) Cross-National Data-Set edited by C. Haerpfer, R. Inglehart, A. Moreno, et al. JD Systems Institute & WVSA Secretariat. Data File Version 3.0.0. 

EVS. 2022. “EVS Trend File 1981-2017.” ZA7503 Data File Version 3.0.0. 

I saved the IVS dataset with the name of IVS.dta

The "country_origin.do" generates the historical values from the country of origin of second-generation immigrants used in the analysis. It also generates the dataset with social trust averaged by waves 1-3 and waves 4-7
